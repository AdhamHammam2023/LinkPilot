# Getting help

1. **Built-in help:** LinkPilot has a Help page with a topic for every feature (left sidebar → Help).
2. **[FAQ](FAQ.md):** answers to the most common questions about speed, the extension, video sites, SmartScreen and updates.
3. **[Install guide](INSTALL.md):** setup, video tools and the browser extension.
4. **Report a problem:** [open an issue](https://github.com/AdhamHammam2023/LinkPilot/issues/new/choose) using the bug report template.
5. **Ask for a feature:** use the feature request template.

When you report a problem, please include your LinkPilot version (Settings → About) and your Windows version. Include the link that failed too, if you can share it.
